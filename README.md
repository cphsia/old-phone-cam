# 舊機監視器

把舊手機變成遠端監視器（類似「阿福管家 AlfredCamera」），單一 `index.html`，免安裝 App、免註冊。

## 功能
- 攝影機模式：即時影像＋聲音、移動偵測（附截圖）、遠端切換前後鏡頭、手電筒、警報器、螢幕常亮、黑屏省電、開網頁自動進入攝影機模式
- 觀看模式：QR Code 或「代碼＋PIN」配對、按住對講、錄影存到手機、截圖、夜視增強、全螢幕、靈敏度調整、移動通知（震動＋提示音＋系統通知）、自動重連、常用攝影機清單
- 影像走 WebRTC 點對點加密，配對訊號經 PeerJS 公用伺服器，不存任何影像

## 部署（必須 https，相機才會開）
1. 在 GitHub 建一個 repo（例：`old-phone-cam`），上傳 `index.html`
2. Settings → Pages → Branch 選 `main` / root → Save
3. 約 1 分鐘後網址為 `https://<帳號>.github.io/old-phone-cam/`

## 使用
1. 舊手機開網址 →「這支當攝影機」→ 允許相機、麥克風，接上充電器
2. 你的手機掃畫面上的 QR Code（或手動輸入代碼與 PIN）
3. 之後從首頁「我的攝影機」一鍵連線

## 限制
- iPhone 當攝影機時，網頁不能切到背景或鎖屏，請保持畫面開著（可用黑屏省電）
- 兩邊都在嚴格 NAT（部分 4G / 公司網路）時可能連不上，需要另外架 TURN 伺服器
- 錄影存在觀看端；攝影機端不錄 24 小時
